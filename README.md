# Intelligent-Runway-Safety-System
Arduino-based runway safety and collision prevention system using ultrasonic and IR sensors
Project Title
Intelligent Runway Safety & Collision Prevention System

Problem
Runway incursions and unauthorized movement can create serious
safety risks in airport operations.

Solution
An Arduino-based prototype that uses ultrasonic and IR sensors
to detect objects/aircraft movement and provide visual and
audio alerts.

Hardware
- Arduino Uno
- 2 × Ultrasonic Sensors
- IR Sensor
- LEDs
- Buzzer
- Resistors

Working
1. Sensors continuously monitor the runway area.
2. Ultrasonic sensors detect approaching objects.
3. IR sensor detects movement/presence.
4. Arduino processes the sensor data.
5. LEDs indicate the safety status.
6. Buzzer provides an alert during dangerous conditions.
